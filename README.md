# Сайт учёта ПФЦ на GitHub Pages

1. Распакуйте архив. В репозитории GitHub через Add file → Upload files загрузите index.html, app.js, Code.gs, pfc-chrome.zip, setup-extension.ps1 и README.md в корень ветки main.
2. В Settings → Pages выберите Deploy from a branch, main, / (root), Save. После публикации нажмите Visit site и скопируйте адрес сайта.
3. На складе в папке с распакованными файлами откройте PowerShell и выполните команду ниже. Вставьте адрес GitHub Pages. Скрипт настроит кнопку расширения и привязку к вашему сайту.
   
   powershell -NoProfile -ExecutionPolicy Bypass -File .\setup-extension.ps1

4. Откройте chrome://extensions. Выключите прежнее расширение ПФЦ, включите режим разработчика и нажмите «Загрузить распакованное расширение». Выберите warehouse-extension/pfc-chrome.
5. В Google Таблице нажмите Расширения → Apps Script. Обновите Code.gs комплектным файлом. Сохраните, выполните setup. Скопируйте ключ из журнала. В управлении развёртываниями измените текущее веб-приложение, выберите новую версию и разверните. Сохраните адрес /exec.
6. На складском ПК нажмите значок расширения. На открывшемся сайте нажмите «Подключить склад», введите адрес /exec и ключ, включите обработку на этом компьютере и подключитесь. На другом компьютере откройте тот же сайт и подключите ту же таблицу. Выберите МХ и нажмите «Обновить».
7. Расширение использует вход WB на складском ПК. Во сне новые проверки приостанавливаются. До подключения таблицы сайт отображает демонстрационные данные. Рабочий ключ храните вне GitHub.
