# GRIZZLY HUG STORAGE · 5.4 для GitHub Pages

## Первый запуск на Windows

1. Распакуйте основной архив. В репозитории GitHub выберите Add file → Upload files. Загрузите index.html, app.js, Code.gs, pfc-chrome.zip и README.md в корень ветки main. Нажмите Commit changes. Рабочий ключ вводится только на сайте.
2. В Settings → Pages выберите Deploy from a branch → main → / (root) → Save. Откройте опубликованный адрес через Visit site.
3. Для первого теста создайте отдельную Google Таблицу. В ней нажмите Расширения → Apps Script, откройте Code.gs. Скопируйте весь текст из комплектного Code.gs, сохраните. Выберите функцию setup и нажмите Выполнить. Подтвердите доступ. Сохраните ключ из журнала выполнения. Скрипт запишет идентификатор таблицы и создаст очередь. Для этой сборки используется собственная схема листов. Переход с прежней базы и перенос истории требуют отдельной сверки.
4. В Apps Script нажмите Начать развертывание → Новое развертывание → Веб-приложение. Выполнение от вашего имени, доступ «Все». Нажмите Развернуть и скопируйте адрес, который заканчивается на /exec.
5. На складском Windows-ПК распакуйте вложенный pfc-chrome.zip. В Chrome откройте chrome://extensions, отключите прежний обработчик ПФЦ. Включите «Режим разработчика», нажмите «Загрузить распакованное расширение», выберите папку pfc-chrome с manifest.json. В этом профиле должен действовать вход в WB; в кабинете должен быть выбран ПФЦ 399276 и поиск «По МХ».
6. На складском ПК откройте опубликованный сайт github.io и нажмите значок расширения ПФЦ через меню пазла Chrome. В форме введите URL /exec и ключ. Нажмите «Включить обработку на этом компьютере», затем «Подключить».
7. На другом компьютере откройте тот же сайт → Настройки → Подключить склад. Введите тот же URL и ключ. Устанавливать расширение здесь не требуется.
8. Откройте «Адресное хранение», найдите 02.01.02, откройте карточку и нажмите «Проверить эту ячейку». На обзоре появится состояние задания. При первом подключении очередь может ждать до следующего опроса расширения. По окончании откройте карточку ещё раз и сверьте БК, количество и время.
9. Проверьте 04.01.01. Для ячейки с несколькими страницами расширение сверяет количество уникальных БК с заголовком WB. При расхождении появляется ошибка; прежний результат сохраняется.
10. Кнопка «Обновить данные» в обзоре запускает сверку всех зарегистрированных адресов. Исходный диапазон — 135 МХ, стеллажи 02–10, пять полок и три ячейки. Дополнительные двузначные адреса можно сохранить через генератор. В «Синхронизации» доступны пауза, продолжение и остановка. Пауза действует после текущей ячейки.

Сайт показывает время последней проверки каждой ячейки по Москве. Когда складской ноутбук спит, доступны сохранённые остатки. Для получения новых данных нужны работающий Chrome, сеть и действующий вход в WB. Расширение открывает временное отдельное окно Chrome без запроса фокуса. Для доступа к складу используется ключ Apps Script. Дневная история обновляется в дни чтения снимка с сайта.
